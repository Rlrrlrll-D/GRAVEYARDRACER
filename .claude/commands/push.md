Отправь текущие изменения на GitHub-хаб. Шаги:

1. Покажи `git status --short` и `git diff --stat`, чтобы было видно, что уходит.
2. `git add -A`.
3. Создай коммит с кратким осмысленным сообщением на основе изменений
   (если ниже в `$ARGUMENTS` есть текст — используй его как суть сообщения).
   Заверши сообщение обязательным футером:
   `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`
4. `git push origin main`. Связь бывает рваная — при сетевой ошибке повтори один раз.
5. Сообщи хеш коммита и результат пуша.

Не создавай новую ветку — это личное зеркало, коммитим прямо в main.
