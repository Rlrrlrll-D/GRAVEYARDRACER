# Окружение и ландшафт кладбища — гайд

## 1. Установка новых скриптов

| Файл | Тип | Куда |
|---|---|---|
| `EnvironmentConfig.lua` | ModuleScript | ReplicatedStorage |
| `AtmosphereSetup.server.lua` | Script | ServerScriptService |
| `GraveyardAmbience.server.lua` | Script | ServerScriptService |
| `FlickerLight.server.lua` | Script | ServerScriptService |

После вставки `AtmosphereSetup` сразу настроит туман/небо/цветокоррекцию
при запуске — можно сразу нажать Play и увидеть эффект.

**Не забудьте** заменить `rbxassetid://0` в `GraveyardAmbience` на реальные
ID звуков ветра и грома из Toolbox → Audio (см. TODO-комментарии в файле) —
иначе получите ту же ошибку "Asset is not approved", что и с двигателем.

## 2. Рельеф (Terrain)

Открой вкладку **Terrain** (Home → Editor → Terrain, или View → Terrain).

**Принцип: трасса должна быть ровной, а вокруг — рельеф.**
1. Инструмент **Draw/Grow** с материалом **Ground** или **Mud** — набросай
   общую площадку под кладбище.
2. Инструмент **Sculpt/Smooth** — по краям трассы подними невысокие холмы
   (5–15 studs), чтобы обрамить путь и скрыть горизонт.
3. **Саму дорогу, по которой едет машина, оставь максимально ровной** —
   VehicleSeat плохо ведёт себя на резких неровностях террейна. Если хотите
   разнообразия — лучше используйте отдельные Part'ы с небольшим уклоном
   поверх плоского Terrain, а не резкие бугры самого Terrain.
4. Материалы: **Grass** сделай тусклым (используй Rock/Ground пятнами —
   ровный зелёный газон на кладбище смотрится неуместно, лучше комбинация
   Ground + Mud + редкие пятна Grass).
5. В низинах вдоль трассы — необязательно, но красиво: тонкий слой воды
   (Water material) или просто визуальный туман (см. п.4) создаёт ощущение
   болотистой почвы.

## 3. Skybox и небо

Быстрый вариант — Toolbox → поиск `night sky` или `graveyard skybox` →
перетащить в Lighting. Skybox должен заменить/дополнить объект **Sky**,
который уже создаёт `AtmosphereSetup` (звёзды + луна), — если возьмёте
готовый skybox с текстурами, script не будет их трогать, просто выставит
StarCount и размер луны.

Если готового решения нет — стандартного чёрного неба + звёзд +
`Atmosphere`-тумана из скрипта уже достаточно для мрачной атмосферы.

---

## 4. Туман у земли (Ground Fog)

`Atmosphere.Haze` в скрипте уже даёт лёгкую дымку. Для более выраженного
"стелющегося" тумана над землёй:

1. Создай плоский **Part**, `CanCollide = false`, `CanQuery = false`,
   `Transparency ≈ 0.85`, серо-голубой цвет, растяни по всей площади трассы
   чуть выше земли (0.5–2 studs).
2. Добавь внутрь **ParticleEmitter** с медленными, крупными полупрозрачными
   частицами (Speed 1–3, Lifetime 8–15, Transparency 0.7→1).
3. Расставь несколько таких "туманных" частей у низин и рядом с могилами —
   не по всей карте сразу, точечно выглядит убедительнее.

## 5. Декорации — что расставить

**Обязательный набор:**
- **Надгробия** — уже используются как теги `Hazard` и `Grave`. Разной
  формы (кресты, плиты, обелиски) для разнообразия.
- **Мёртвые деревья** — искривлённые, без листвы, тёмно-серые/чёрные.
  Toolbox: `dead tree`, `spooky tree`.
- **Кованая ограда** по периметру кладбища — держит игрока в границах
  трассы и добавляет атмосферы.
- **Ворота/арка на входе** — хороший landmark для старта гонки.
- **Мавзолей или часовня** — один крупный акцентный объект в центре или
  на повороте трассы.
- **Фонарные столбы** вдоль трассы — воткни в них PointLight и тегируй
  `FlickerLight` (скрипт уже готов).

**Мелкие детали (по желанию, для атмосферы):**
- Вороны на ограде (статичные модели или с лёгкой анимацией взлёта при
  приближении машины).
- Паутина на арках/деревьях (Decal или полупрозрачная текстура).
- Разбитые фонари/повозки как дополнительные `Hazard`.
- Свечи/фонарики у некоторых могил (маленький PointLight, тёплый оттенок,
  без мерцания — контраст с холодным лунным светом).

## 6. Композиция трассы

- Трасса — **петля или восьмёрка** через кладбище, не прямая линия: так
  веселее и есть место для поворотов, где легко влететь в надгробие.
- Чередуй **открытые участки** (для разгона и стрельбы по зомби) с
  **узкими проходами между надгробиями** (где легко зацепить `Hazard`).
- Могилы (тег `Grave`) размести и вдоль трассы, и чуть в стороне — так
  зомби будут вылезать не только прямо под колёсами, но и подтягиваться
  издалека, что честнее для игрока.
- Не перегружай сами края дороги высокими объектами вплотную к трассе —
  оставь запас 3–4 studs между краем проезжей части и декором, чтобы
  случайное "зацепить бампером" не превращалось в стену.
